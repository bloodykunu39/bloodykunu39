## 👋 About Me

I'm a student at the **Indian Institute of Science (IISc), Bangalore**, working on machine learning end to end:
retrieval and LLM pipelines, large-scale tabular ML, and deep learning on biomedical signals.

- 🔭 Working on LLM systems: retrieval, reranking and long-form generation
- 🧪 Research: orthogonal-polynomial image encodings for 12-lead ECG classification
- 🏆 Amazon ML Challenge 2026: **0.988** macro F0.5 on the public leaderboard (team *charlies*)
- 💬 Ask me about RAG, LightGBM, PyTorch, or squeezing models onto small GPUs
